# v1.1.41：邮箱连接复用与限流恢复

## 配套版本

| 组件 | 版本 |
|---|---|
| 浏览器扩展 | 1.1.41 |
| Windows 桌面端 | 1.1.36 |
| Native Mail Companion | 1.1.2 |

## 修复内容

- 一轮 IMAP 扫描复用本地组件进程与邮箱连接，避免逐封邮件重复登录；同账号命令串行执行，重复扫描请求合并。
- 插件与桌面端通过跨进程互斥避免同时扫描同一邮箱；异常退出后释放占用，扫描结束、断线或超时后回收连接。
- 保留 `RATE_LIMITED`、`ACCOUNT_BUSY` 和可选 `retryAt`，区分登录限流、授权错误及网络超时，并显示中文原因。
- 限流后按 30、60、120 分钟退避，两端共享本机冷却状态，连接测试也遵守冷却；到期自动重试，成功访问后重置。这是应用重试策略，不是服务商解封时间承诺。
- 普通失败保留有效游标，完整页面保存进度，失败页不越过；已有审核邮件跳过重复正文下载，保留本地摘要重新匹配和补齐时间的能力。
- 扫描不覆盖人工确认／忽略状态，不再按旧数量上限裁掉已有审核及去重记录。
- 新版客户端检查 `imap-session-v1` 能力，遇到旧 Native 组件明确提示升级；Native 的旧单请求协议及本机同步接口保持兼容。

## 数据与隐私

- 无需迁移业务数据、清空邮箱、删除账号或重新授权；授权码继续保存在系统凭据库。
- 新增独立本机运行状态文件，仅保存账号哈希、占用与冷却信息，不保存授权码或邮件正文。
- 邮件继续只读，不标记已读；招聘识别、岗位匹配、日期规则、投递管理、提醒和本机同步行为不在此次修改范围。
- 发布物只包含项目程序与通用文档，不包含个人投递记录、简历、邮箱配置、授权码、本机验收记录、私有备份或旧安装包。

## 验证范围

- 扩展 519 项、桌面端 111 项、Native 29 项测试通过，共 659 项；三端类型检查与构建通过。
- 模拟读取 60 封邮件，整轮只登录一次；覆盖超时中断、连续点击、两端争用、异常退出、冷却与重启恢复、分页进度及审核去重。
- 回归既有招聘邮件识别、时间提取、投递与本机同步测试；桌面主进程、界面及打包成品完成隔离启动检查。
- 三个安装包版本与 SHA256 已核对，包内未包含个人运行数据。
- 真实邮箱恢复仍需在服务商冷却结束后受控验证；模拟测试及组件连通检查不代表真实邮箱已恢复。

## 升级与回退

从 [发布页](https://github.com/ikang2001/Job-Application-Helper/releases/tag/v1.1.41) 下载最新三个组件及 SHA256 文件。先备份个人数据并保留本地旧安装包，再按 [保留数据升级指南](../mail-recovery-upgrade.md) 操作。

扩展必须覆盖到原加载目录，再点击原扩展的“重新加载”，保持扩展 ID 不变；不要删除后重新添加。桌面端安装到原目录，Native 使用固定目录。回退只恢复程序文件，不删除当前数据，也不要用旧备份覆盖升级后新增的投递记录。
